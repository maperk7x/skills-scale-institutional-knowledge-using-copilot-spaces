# OctoAcme Project Management Docs

Welcome to the OctoAcme Project Management Docs. This README provides an overview of how OctoAcme runs projects, including a summary of our project management processes and quick links to detailed documentation.

## Project Management Processes Summary
OctoAcme’s approach ensures customer-first delivery, transparency, and continuous improvement. Key elements include:

- **Principles:** Customer-first and iterative delivery, clear ownership, data-informed decisions, psychological safety.
- **Defined Roles:** Project Manager, Product Manager, Developer, Stakeholder, QA.
- **Project Lifecycle:** Initiation → Planning → Execution → Release → Retrospective.
- **Core Artifacts:** Project Charter, Roadmap, Backlog, Acceptance Criteria, Risk Register, Retrospective notes.
- **Workflows:** Project boards and PR conventions, regular demos, risk register maintenance, escalation paths.
- **Communication Cadence:** Weekly PM/PdM syncs, twice-weekly standups, monthly stakeholder updates, ad-hoc escalations as needed.
